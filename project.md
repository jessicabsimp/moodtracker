# Warm & Organic Health & Mood Dashboard

## Overview
A modern, responsive wellness dashboard featuring an asymmetrical bento grid, earthy design tokens, and modular feature slots prepared for future automation and API integrations.

## Core Files
- `index.html`: Main UI dashboard structure containing top-row bento cards and lower detail panels.
- `styles.css`: Warm cream aesthetic (`#F8F4EC`), serif display typography, responsive 3-column CSS Grid.
- `app.js`: Local storage handling, DOM rendering, and mood entry submission logic.

## Design Tokens
- Background: `#F8F4EC`
- Cards: `#FFFDF8` with 18px border-radius
- Palette: Olive (`#56613B`), Sage (`#A7AF8B`), Terracotta (`#C96F4A`), Warm Gold (`#D8A646`)
- Typography: 'DM Serif Display' (Headings) + 'Inter' (UI text)
